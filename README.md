One funny text message from your future self, 136 characters. The program
writes the single line to `/output/entry.txt` — deterministic, no network.

The line: *"It's you from 2041. The 'temporary' tattoo lasted 40 years, the
marriage lasted 6 months, and the houseplant outlived us both. Water it."*

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
